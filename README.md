# qa\_python



Список проверок



1. Добавила проверку метода add\_new\_book (исключая добавленную проверку в примере):
* добавление одной книги дважды
* проверка на невалидные названия (пустая строка, 41 символ)
* проверка на валидные названия (40 символов)



2\. Добавила проверку метода set\_book\_genre:

* проверка, что книга и жанр существуют
* проверка, что книга и жанр несуществуют



3\. Добавила проверку метода get\_book\_genre:

* книга без жанра
* несуществующая книга



4\. Добавила проверку метода get\_books\_with\_specific\_genre:

* проверка, что есть несколько книг нужного жанра



5\. Добавила проверку метода get\_books\_genre:

* проверка, что названия книг правильно сохранились в словаре



6\. Добавила проверку метода get\_books\_for\_children:

* проверка, книг с "детскими" жанрами



7\. Добавила проверку метода add\_book\_in\_favorites:

* проверка добавления книги в избранное
* проверка, что нельзя добавить в избранное дважды



8\. Добавила проверку метода delete\_book\_from\_favorites:

* проверка удаления книги из избранного



9\. Добавила проверку метода get\_list\_of\_favorites\_books:

* проверка, что список избранного пуст
* проверка, что выдаётся список избранного
